# Roadmap

Planned features and milestones for lion-LLM.

Short-term (next 3 months)
- Improve API for episodic control and state snapshots
- Add more unit tests and CI coverage
- Add tooling to export/import model state

Mid-term (3–12 months)
- Add lightweight model visualizations in `lion_server/public`
- Implement persistence migrations and versioning
- Add language bindings (Python) for `lion_core` APIs

Long-term (12+ months)
- Distributed training experiments
- Integration with external datasets and evaluation suites
- Performance optimizations and profiling

Contributing to roadmap
----------------------

Open issues and PRs that implement these items are welcome. Discuss plans in issues before significant design work.
