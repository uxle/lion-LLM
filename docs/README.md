# Documentation Index

Welcome to the lion-LLM documentation. This folder contains in-depth guides, architecture notes, API documentation, data format descriptions, and developer workflows.

Files:

- `architecture.md` — high-level system architecture and module responsibilities
- `getting_started.md` — setup and quickstart for new contributors
- `developer_guide.md` — code layout, build, and debugging tips
- `api.md` — HTTP/WebSocket API for `lion_server`
- `data_format.md` — descriptions of training and session data formats
- `testing.md` — how to run and extend tests and CI
- `security.md` — security considerations and responsible disclosure
- `roadmap.md` — planned features and milestones
- `changelog.md` — project change log

Use these documents as your primary source of truth for working with this repository.
